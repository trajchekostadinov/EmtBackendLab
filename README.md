# E-Shop Book Management System

Full-stack e-shop application for managing books, authors, countries, and shopping carts.

## Technologies

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- PostgreSQL


### Frontend
- React
- TypeScript
- Material UI


---

## Features

- JWT authentication & authorization
- CRUD operations for books
- Browse books, authors, and countries
- Filter books by state 
- REST API architecture
